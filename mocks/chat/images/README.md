# 테스트 냉장고 이미지

동일한 냉장고와 식재료를 서로 다른 구도로 생성한 Vision 입력 테스트 이미지입니다.

| 파일 | 구도 |
|---|---|
| `fridge-overview.png` | 냉장고 전체 |
| `fridge-upper-shelves.png` | 상단·중간 선반 중심 |
| `fridge-lower-shelves.png` | 하단 선반·서랍 중심 |

Swagger에서 사용할 수 있는 Base64 요청은 상위 폴더의
[`request-image-base64.json`](../request-image-base64.json)입니다.
